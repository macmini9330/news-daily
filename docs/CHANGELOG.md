**成果**：v1 上线，22 条/天 → 6-7 条入选四板块。git commit `1394007`、`5586a09`

## 任务 8：首页汇率卡片模块（2026-08-21）

**背景**：用户要求在首页三统计卡片右侧新增当日汇率小模块，展示哈萨克斯坦坚戈与人民币、美元汇率。

**做了什么**：
- 数据源调研：open.er-api.com/v6/latest/KZT（免费、无需 key、国内可达，UTC 每日 00:02 更新）
- 新建 scraper/fetch_rates.py：抓汇率 → /tmp/kz_rates.json（cny/usd/kzt + usd_cny/usd_kzt + api_time）
- run_daily.py 增加 1.5 步「抓取汇率」（失败不阻断流水线）
- generate_kz_html.py：generate_index 生成汇率表格卡片（第 4 张，与三卡片并列）
- 用户四次拍板迭代样式：
  1. 卡片形式（人民币:美元:坚戈=xx:xx:xx，4位小数）
  2. 改小表格展示，标题「当日汇率（更新时间：xxxx年xx月xx日）」
  3. 改三字段横排（人民币红/美元绿/坚戈青），标题居中加粗
  4. 表格增加「美元为1」基准行 + 仅标题加粗、行内无标注文字

**踩坑**：
- Python 版本旧不支持 `dict | None` 类型标注 → 去掉
- 美元基准行必须用 API 原始值计算（cny_per_usd = cny_per_kzt/usd_per_kzt），避免二次四舍五入误差
- api_time 是 UTC，要 strptime + astimezone(+8) 转北京时间显示（注意跨天）
- 曾用 ::before 加「1美元 =」标注被用户纠正——行内不得有文字/符号，仅纯数值

**最终形态**（定稿）：
```
当日汇率（更新时间：2026年08月21日）  ← 居中加粗
┌────────┬────────┬─────────┐
│ 人民币  │ 美元   │  坚戈    │ ← 红/绿/青，不加粗
│ 1.0000 │ 0.1482 │ 67.7645 │ ← 人民币为1
│ 6.7476 │ 1.0000 │ 457.2474│ ← 美元为1
└────────┴────────┴─────────┘
```

**成果**：首页汇率表格上线（线上 HTTP 200 验证），git commits `47ff931`→`313cffb`（5 个提交）；技能 news-daily-digest #18 已更新。
